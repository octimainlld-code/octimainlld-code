# Hi, I'm Guy Uoliel

**eCommerce operator turned systems builder.** I spent 11 years running Shopify and Magento stores for brands across the US, Europe and Israel and launching Amazon private-label products. Now I design, build and ship the business systems I wish I'd had back then, using AI-assisted development.

I'm not a traditional software engineer. I'm an operator who builds: I start from the commercial problem (revenue, conversion, support load, wasted hours) and ship a working tool that fixes it.

**Founder of [Octopus Systems](https://octopus-systems.vercel.app)**, an operating layer that gives a business one clear picture of its customers, team, work and numbers.
